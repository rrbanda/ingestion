# Getting Started with LSS

This guide helps you get started with the LSS (Llama Stack Service) plugin for Backstage.

## Prerequisites

- Backstage instance running
- Llama Stack server configured
- MCP servers (optional, for tool execution)

## Quick Start

1. Install the plugin packages
2. Configure `app-config.yaml`
3. Add the plugin to your Backstage app
4. Start chatting with AI

## Features

- **RAG Support**: Query your knowledge base
- **MCP Tools**: Execute actions via Model Context Protocol
- **Streaming**: Real-time response streaming
- **HITL**: Human-in-the-loop approval for sensitive operations
